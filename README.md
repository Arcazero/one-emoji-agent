One emoji that stands for an AI agent — an entry for make.fun's "Your Agent in One Emoji" bounty ($2 in USDC). See the bounty: https://make.fun/c/u-boge-your-agent-in-one-emoji-db30c1e4

The emoji is 🦾 (mechanical arm). An agent is not a face that chats — it is a hand that acts: it reaches out on your behalf, picks up the right tool, and does the work.

## Run it

```sh
python3 main.py
```

This writes the single emoji to `/output/entry.txt`.
